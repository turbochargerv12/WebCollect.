# Chrome Web Store listing

## Name

WebCollect — Collect, Edit, Export

## Short description

Collect webpage elements, arrange them with your notes, and export HTML or PDFs with selectable text.

## Detailed description

Bring the useful parts of the web into one document.

WebCollect lets you select webpage elements, organize your captures, add your own notes, and export a readable document. Use it to keep study material, research passages, lists and tables together while you work.

COLLECT
• Open the sidebar and turn on Collect.
• Hover to highlight an element, then click to add it.
• Press Escape to stop collecting.
• Keep captures from multiple webpages in one collection.

EDIT
• Reorder or remove captured blocks.
• Edit text and add notes between captures.
• Adjust block width, height and scale.
• Choose A4 or Long page and save your edits.

EXPORT
• Download HTML with linked images.
• Generate a PDF with selectable text where the source contains text.
• Choose a filename and save location.

DATA AND PERMISSIONS
Captures, notes, webpage titles and source URLs are stored locally in your browser profile. There is no WebCollect account, analytics, cloud sync or developer-operated collection server.

Captured remote images can still request data from their original hosts during preview, printing or opening exported HTML. HTML exports are not fully offline archives.

Website access enables collection on regular HTTP/HTTPS pages. The debugger permission is used only to generate PDFs from the WebCollect editor tab; downloads saves the PDF.

LIMITATIONS
Browser-protected pages and some embedded content cannot be collected. Image-only text does not become searchable through OCR. Large captures can reach browser storage limits.

WebCollect is free and open source under the MIT license.

## Review notes

No login is required. Load a regular webpage, open WebCollect, select Collect, capture a paragraph, press Escape, and open Preview Collection. Add a note and export HTML or PDF. PDF export attaches the debugger only to the editor, calls Page.printToPDF, downloads the PDF and detaches in finally. No externally hosted JavaScript is executed.
